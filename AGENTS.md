# Terra Tunis — monorepo

Two apps:

- **`storefront/`** — Next.js 16 customer storefront (the shop UI).
- **`backend/`** — Medusa v2 commerce engine (products, orders, payments, admin).

Run each from its own folder; see `docs/` for setup, and `README.md` for the map.
